城市景点与美食推荐

本指南供出差期间利用空闲时间游览使用。交通出行与住宿区域建议见《城市出差实用指南》。

一、北京

1. 必去景点
   - 故宫博物院：明清皇宫，建议预留3-4小时，周一闭馆，需提前7天官网实名预约
   - 天安门广场：与故宫相邻，看升旗需凌晨到达，需提前预约
   - 八达岭长城：距市区约70公里，往返需一整天，建议早出发避堵
   - 颐和园：皇家园林，建议预留半天，春季和秋季景色最佳
   - 天坛公园：祈年殿为标志性建筑，建议预留2小时

2. 近郊与周边
   - 慕田峪长城：人比八达岭少，适合想避开人群的游客
   - 古北水镇：长城脚下的水乡古镇，适合一日游
   - 承德避暑山庄：距京约230公里，需安排2天

3. 特色美食
   - 北京烤鸭：全聚德、便宜坊、大董等，人均150-300元
   - 老北京小吃：豆汁焦圈、卤煮、炒肝、爆肚，推荐护国寺小吃、姚记炒肝
   - 铜锅涮肉：东来顺、南门涮肉为代表
   - 集中区域：簋街（夜宵）、牛街（清真）、前门大栅栏（老字号）

4. 商务宴请推荐
   - 高端：国贸、金融街周边的高端中餐厅
   - 有特色：胡同里的四合院餐厅，适合接待外地客户
   - 注意：长安街沿线及天安门周边餐厅安保严格，建议提前确认

5. 半天/一天怎么安排
   - 半天：天安门广场 + 故宫（下午场）
   - 一天：上午八达岭长城，下午返回市区逛南锣鼓巷

二、上海

1. 必去景点
   - 外滩：万国建筑博览群，夜景最佳，建议傍晚前往，预留1.5小时
   - 陆家嘴：东方明珠、上海中心、环球金融中心，"三件套"观景台选一个即可
   - 豫园与城隍庙：江南古典园林 + 老城厢，建议预留2小时
   - 田子坊与新天地：石库门改造的文创街区，适合散步
   - 上海博物馆：青铜器与书画馆藏丰富，需提前预约

2. 近郊与周边
   - 朱家角古镇：距市区约50公里，江南水乡，半日可游
   - 迪士尼度假区：需一整天，建议工作日前往
   - 苏州、杭州：高铁30分钟至1.5小时，可安排周末延伸行程

3. 特色美食
   - 本帮菜：红烧肉、油爆虾、草头圈子，推荐老吉士、兰心餐厅
   - 小笼包：南翔馒头店、佳家汤包
   - 生煎：大壶春（无汤）、小杨生煎（有汤）
   - 集中区域：云南南路美食街、黄河路、进贤路

4. 商务宴请推荐
   - 高端：外滩沿线江景餐厅，人均500元以上
   - 中端：静安寺、新天地周边
   - 注意：外滩景观位需提前一周以上预订

5. 半天/一天怎么安排
   - 半天：外滩 + 南京路步行街
   - 一天：上午豫园城隍庙，下午陆家嘴观景，晚上外滩看夜景

三、广州

1. 必去景点
   - 广州塔（小蛮腰）：地标建筑，观景台与摩天轮需提前购票
   - 沙面岛：欧陆风情建筑群，适合拍照散步，预留1.5小时
   - 陈家祠：岭南建筑艺术代表，木雕砖雕精美，预留1.5小时
   - 越秀公园与五羊石像：市区内的老牌公园
   - 珠江夜游：天字码头、大沙头码头均可登船

2. 近郊与周边
   - 长隆旅游度假区：野生动物世界、欢乐世界，需一整天
   - 佛山：地铁直达，祖庙与岭南天地值得一逛
   - 深圳：高铁约30分钟

3. 特色美食
   - 早茶：点都德、陶陶居、广州酒家，建议上午9点前到
   - 烧腊：烧鹅、叉烧，推荐炳胜、惠食佳
   - 糖水：双皮奶、姜撞奶，推荐南信牛奶甜品
   - 集中区域：上下九、北京路、文明路

4. 商务宴请推荐
   - 高端：珠江新城、琶洲会展中心周边
   - 有本地特色：老字号粤菜馆，适合接待外地客户体验粤菜
   - 注意：广交会期间（4月、10月）酒店与餐厅极度紧张，务必提前预订

5. 半天/一天怎么安排
   - 半天：沙面岛 + 上下九步行街
   - 一天：上午陈家祠，下午广州塔，晚上珠江夜游

四、深圳

1. 必去景点
   - 深圳湾公园：海滨栈道，适合骑行与散步，可远眺香港
   - 世界之窗：微缩景观主题公园，适合家庭出行
   - 华侨城创意园（OCT-LOFT）：文创园区，有展览与独立书店
   - 莲花山公园：山顶可俯瞰福田CBD全景
   - 大鹏所城与较场尾：东部海滨，需一整天

2. 近郊与周边
   - 东部华侨城：大梅沙、小梅沙海滨
   - 香港：福田/深圳湾口岸过关，需港澳通行证
   - 东莞、惠州：高铁或城际约30-60分钟

3. 特色美食
   - 潮汕菜：牛肉火锅、卤鹅，推荐八合里、陈鹏鹏
   - 客家菜：盐焗鸡、酿豆腐
   - 海鲜：南澳、蛇口海上世界
   - 集中区域：华强北、COCO Park、海上世界

4. 商务宴请推荐
   - 高端：福田CBD、深圳湾一号周边
   - 科技园区：南山科技园周边，适合接待技术类客户
   - 注意：深圳餐饮偏年轻化，正式宴请建议选粤菜或潮汕菜馆

5. 半天/一天怎么安排
   - 半天：莲花山公园 + 深圳湾公园
   - 一天：上午华侨城创意园，下午世界之窗或海滨

五、杭州

1. 必去景点
   - 西湖：建议环湖骑行或乘船，苏堤春晓、断桥残雪为经典，预留半天
   - 灵隐寺与飞来峰：需购飞来峰门票 + 灵隐寺香花券
   - 西溪湿地：城市湿地，适合半天，秋季芦苇最佳
   - 河坊街与南宋御街：老城区步行街
   - 龙井村与九溪十八涧：茶园徒步，适合半日

2. 近郊与周边
   - 千岛湖：距市区约2小时车程，需一整天
   - 乌镇、西塘：江南水乡，高铁或大巴约1小时
   - 莫干山：避暑胜地，适合周末

3. 特色美食
   - 杭帮菜：西湖醋鱼、东坡肉、龙井虾仁，推荐外婆家、绿茶、楼外楼
   - 面食：片儿川、虾爆鳝面，推荐奎元馆
   - 小吃：定胜糕、葱包桧、猫耳朵
   - 集中区域：河坊街、胜利河美食街、in77周边

4. 商务宴请推荐
   - 高端：西湖景区内餐厅，环境好但需提前订位
   - 中端：武林广场、钱江新城周边
   - 注意：G20会场周边及西湖核心景区部分区域有交通管制

5. 半天/一天怎么安排
   - 半天：西湖（断桥 → 白堤 → 孤山 → 苏堤）
   - 一天：上午西湖游船，下午灵隐寺，晚上河坊街

六、成都

1. 必去景点
   - 大熊猫繁育研究基地：建议早上7:30前到，熊猫上午最活跃
   - 宽窄巷子与锦里：老成都街区，适合傍晚
   - 武侯祠与杜甫草堂：三国与诗歌文化，各预留1.5小时
   - 都江堰与青城山：距市区约1小时，需一整天
   - 人民公园鹤鸣茶社：体验成都盖碗茶与采耳

2. 近郊与周边
   - 乐山大佛与峨眉山：高铁约1小时，建议2天
   - 西岭雪山：冬季滑雪，距市区约2小时

3. 特色美食
   - 火锅：蜀大侠、小龙坎、大龙燚，人均100-150元
   - 川菜：麻婆豆腐、回锅肉、夫妻肺片，推荐陈麻婆豆腐、明婷饭店
   - 小吃：钟水饺、龙抄手、担担面、兔头
   - 集中区域：玉林、建设路、奎星楼街

4. 商务宴请推荐
   - 高端：太古里、金融城周边
   - 有特色：川菜老字号，适合接待外地客户
   - 注意：本地客户多能接受麻辣，外地客户建议提前确认口味

5. 半天/一天怎么安排
   - 半天：大熊猫基地（上午）+ 宽窄巷子（傍晚）
   - 一天：都江堰 + 青城山

七、西安

1. 必去景点
   - 秦始皇兵马俑：距市区约40公里，往返需一整天，建议请讲解
   - 西安城墙：可租自行车环城骑行，全程约2小时
   - 大雁塔与大唐不夜城：夜景与灯光秀，建议傍晚前往
   - 陕西历史博物馆：需提前预约，建议预留3小时
   - 回民街：美食街区，与钟鼓楼相邻

2. 近郊与周边
   - 华山：高铁约30分钟，建议一整天或住一晚
   - 法门寺：距市区约2小时

3. 特色美食
   - 面食：biangbiang面、臊子面、油泼面
   - 泡馍：老孙家、同盛祥，需自己掰馍
   - 肉夹馍：秦豫肉夹馍、子午路张记
   - 集中区域：回民街、永兴坊、洒金桥

4. 商务宴请推荐
   - 高端：高新区、曲江新区周边
   - 有特色：仿唐宴、陕菜馆，适合接待外地客户

5. 半天/一天怎么安排
   - 半天：城墙骑行 + 回民街
   - 一天：兵马俑 + 华清池

八、通用建议

1. 时间安排
   - 出差期间游览应安排在非工作时间，不得影响公务
   - 建议单个景点预留时间不少于1.5小时，避免赶场
   - 旺季（节假日、暑期）景点人流大，务必提前预约购票

2. 费用说明
   - 游览产生的门票、交通、餐饮费用属于个人消费，不予报销
   - 因公务需要陪同客户游览的，需提前审批并按业务招待流程报销

3. 安全提醒
   - 人流密集景区注意随身财物
   - 山区景点注意天气变化，避免单独前往未开发区域
   - 详见《紧急情况处理指南》
